# 星際分數探險隊 (Space Fraction Explorers) — 遊戲規格書 `GAME_SPEC.md`

## 1. 遊戲概覽 (Overview)
- **目標年級與課題：** 小學五年級 (P5) 數學 — 分數運算與應用（繁體中文介面）
- **主題風格：** 宇宙太空探險（太空船能量補給、星球躍遷進度條、可愛太空人與火箭 SVG 插畫、星空粒子背景）
- **技術架構：** 零後端純靜態網頁（`index.html`、`style.css`、`curriculum.js`、`audio.js`、`game.js`），放置於獨立資料夾 `space-fraction-p5/`，可直接部署至 GitHub Pages / Firebase Hosting 或本地開啟。
- **自包含資源與音效：** 全數圖像採用 Inline SVG 與 HTML5 Canvas 繪製，不使用外部圖片或音訊連結；採用 Web Audio API 即時合成輕快太空音效，並於介面右上角提供明顯的「靜音 / 開啟音效」切換按鈕。

## 2. 學習目標與難度分級 (Curriculum & Difficulty)
題庫獨立存放於 `curriculum.js`（純資料結構，易於增刪或替換題目，與遊戲引擎邏輯完全分離）。每個難度每次遊玩隨機抽取 **10 題**（或依序呈現不重複題組）：

1. **簡單 (初級航道 / Easy)：基礎異分母加減與約分**
   - 其中一個分母為另一個的倍數（如 $\frac{1}{2} + \frac{1}{4}$、$\frac{5}{6} - \frac{1}{3}$），練習基礎通分與化為最簡分數。
2. **中等 (中級星雲 / Medium)：一般異分母加減與帶分數**
   - 需找最小公倍數 (LCM) 通分，含假分數與帶分數轉換及加減（如 $\frac{2}{3} + \frac{1}{4}$、$1\frac{1}{2} - \frac{2}{3}$）。
3. **困難 (高級躍遷 / Hard)：小五分數乘法與太空情境應用題**
   - 分數乘整數、分數乘分數、帶分數乘法與簡單應用題（如 $\frac{3}{4} \times \frac{2}{5}$、$1\frac{1}{3} \times 6$、燃料消耗情境題）。

## 3. 核心遊戲循環與教學引導 (Core Game Loop & UX)
1. **開始畫面 (Start Screen)**
   - 遊戲標題「星際分數探險隊」與太空船 SVG 角色。
   - 三段難度選擇按鈕：**簡單**、**中等**、**困難**。
   - 顯眼的 **「開始任務」** 主按鈕，以及靜音切換按鈕。
2. **答題畫面 (Gameplay Screen — 10 題回合)**
   - **頂部 HUD：** 星球進度條（1–10 題）、連勝火苗計數器 (Streak)、當前得分，以及音效/返回按鈕。
   - **題目卡片：** 清晰易讀的直式分數排版（分子/分數線/分母），搭配視覺化能量條或圖示。
   - **溫和引導機制 (Gentle Scaffolding)：** 沒有懲罰性的「Game Over」。答錯時卡片輕微左右搖晃，顯示**繁體中文步驟提示**（例如顯示通分後的同分母步驟或分數乘法的約分提示），並搭配 SVG 分數能量條輔助理解，讓小朋友可以重新選擇直到答對。
   - **答對回饋：** 播放歡快音效、噴發彩帶/星星粒子特效，並短暫顯示正向鼓勵語（如「能量充滿！準備躍遷！」）後進入下一題。
3. **結算畫面 (Summary Screen)**
   - 根據表現頒發 1 至 3 顆金色星章，顯示答對題數（首次答對率）、最高連勝紀錄與太空徽章評語。
   - 提供 **「再玩一次」** 與 **「切換難度」** 按鈕。

## 4. 版面配置與跨裝置相容 (Layout & Responsiveness)
- **觸控友善設計：** 所有可點擊按鈕（難度選擇、答案選項、開始/重玩、音效切換）皆保證最小 `48x48px` 點擊區域（選項按鈕設計為寬敞卡片，高度 `>= 64px`），不依賴 hover 觸發任何核心互動，完整支援滑鼠與平板/手機觸控。
- **響應式斷點：**
  - **桌面版 (`1280x800`)：** 置中太空艙控制台佈局，2×2 答案網格，無須捲動即可於單一畫面完成所有操作。
  - **平板直向 (`768x1024`) 與手機版：** 自動調整字級、卡片內距與垂直排列，確保題目分數與 4 個選項清楚不重疊、不溢出視窗。
