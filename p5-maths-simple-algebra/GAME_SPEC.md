# 足球代數 (Soccer Algebra) — 遊戲規格書 `GAME_SPEC.md`

## 1. 遊戲概覽 (Overview)
- **目標年級與課題：** 小學五年級 (P5) 數學 — 香港教育局 2017 課程 5A1 代數的初步認識、5A2 簡易方程（一）（繁體中文介面）
- **主題風格：** 夜間足球場訓練（霓虹草皮、射門／撲救動畫、教練 SVG 吉祥物、粒子慶祝特效）
- **技術架構：** 零後端純靜態網頁（`index.html`、`styles.css`、`questions.js`、`audio.js`、`game.js`），放置於獨立資料夾 `p5-maths-simple-algebra/`，可直接部署至 GitHub Pages 或本地開啟。
- **自包含資源與音效：** 全數圖像採用 Inline SVG 與 HTML5 Canvas 繪製，不使用外部圖片或音訊連結；採用 Web Audio API 即時合成射門／撲救／點擊／星章音效，介面右上角提供「音效：開／關」切換（**預設開啟**）。

## 2. 學習目標與難度分級 (Curriculum & Difficulty)
題庫與產生器獨立存放於 `questions.js`（與畫面／計分邏輯分離）。共 **8 場比賽**，每場固定 **6 題** 新鮮題目（整數 only）：

1. **場次 1–4（5A1）：** 代數初步 — 表達式、代入求值、簡化、匹配等
2. **場次 5–8（5A2）：** 簡易方程 — 平衡步驟、求未知數、文字題分步（選方程 → 求 x → 驗算）

具體題型與參數範圍以 `questions.js` 內 EDB 5A1–5A2 產生器為準，本規格不覆寫課綱內容。

## 3. 核心遊戲循環與教學引導 (Core Game Loop & UX)
1. **開始畫面 (Home)**
   - 標題「足球代數」、教練＋足球 SVG 角色、規則摘要、已收集星數。
   - **開始比賽**、**重設進度**；頂部音效切換。
2. **賽程地圖 (Map)**
   - 八場關卡卡；取得 **至少 1 星** 解鎖下一場。
   - 下一場「已解鎖且尚未取得星」的關卡會有霓虹脈衝動畫提示。
3. **比賽畫面 (Match — 6 題)**
   - **頂部 HUD：** 場次標題、題目進度、**連勝** pill、**入球**（首次答對才計分）。
   - **溫和引導：** 答錯不會 Game Over；第一次錯顯示平衡步驟並允許再射一次（最多 2 次嘗試）。
   - **答對回饋：** 射門動畫、粒子、輪替繁中鼓勵語（如「漂亮射門！」「平衡做得好！」）。
   - **連勝規則：** 整題首次完成 +1；任何 miss 歸零。連勝不影響解鎖／星章門檻（星章只看首次入球數）。
4. **結算畫面 (Result)**
   - SVG 星章填入動畫；統計：首次入球、最高連勝、本場星；徽章評語。
   - 有星時播放星章音效與粒子爆發。
   - **再賽一場**／**返回地圖**。

### 星章門檻（不可變更）
| 首次入球 | 星 |
| --- | --- |
| 5–6 | 3 |
| 3–4 | 2 |
| 1–2 | 1 |
| 0 | 0 |

只保存該場歷史最高星；解鎖下一場需該場 ≥ 1 星。

## 4. 版面配置與跨裝置相容 (Layout & Responsiveness)
- **觸控友善：** 按鈕最小約 `48×48px`；選項／鍵盤鍵夠大；不依賴 hover。
- **響應式：** 桌面雙欄（球場＋答題面板）；窄螢幕垂直堆疊；HUD 在小螢幕改排連勝／入球列。
- **無障礙／動效：** `prefers-reduced-motion` 時關閉視覺動畫與粒子（音效仍由使用者開關控制）。

## 5. 特效與音效 (FX & Audio)
| 事件 | 視覺 | 音效 |
| --- | --- | --- |
| 答對／入球 | 球進門、粒子、鼓勵語 | `playGoal` |
| 答錯／撲救 | 守門員撲救、紅系粒子 | `playSave` |
| 鍵盤／按鈕 | — | `playTap` |
| 結算有星 | 星章 pop、結果粒子 | `playStar` |

進度存在瀏覽器 `localStorage`（`soccer-algebra-stars-v1`），不上傳伺服器。
